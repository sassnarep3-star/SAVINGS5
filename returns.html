Method. APY already includes compounding, so a constant-rate projection is balance = deposit × (1 + APY)years. No rate is assumed: only APYs transcribed from a bank's own page are used. Monthly fees are shown separately and subtracted in the net columns on the Accounts page.

Accounts excluded from the projections

These accounts are in the comparison but not in any return table, because no official numeric APY could be read for them. Leaving them out is deliberate: filling the gap with an estimate would make the tables look complete and be wrong.

  • Chase — Chase Savings(SM): Chase publishes savings rates only after a ZIP code is entered ("In order to see rates table, please provide valid 5-digit zip code"). No static official rate is published, so no APY is asserted here. page checked
  • Bank of America — Advantage Savings: Bank of America publishes rates only in a location-specific PDF requested after ZIP and county selection. The static page carries no rate, so no APY is asserted here. page checked
  • Citibank — Citi(R) Accelerate Savings: Citi renders the savings APY on its own page as the unresolved template token ":BLUE_AccSavings_Rate%", and its footnote says the APY depends on Rate Region, Relationship Tier and promotion. No numeric APY could be read from an official page, so none is asserted. page checked
  • PNC — PNC High Yield Savings(R): The PNC page title carries "3.15% Annual Percentage Yield APY", but the page body returned "This Product Isn't Available in Your Area" and the rate table is ZIP-gated. The 3.15% figure was not confirmed in page content for a New York ZIP, so no APY is asserted. page checked
  • TD Bank — TD Simple Savings: The TD savings page's rate tables are empty in the served HTML (rates are injected after location selection). No numeric APY could be read, so none is asserted. page checked
  • Fifth Third — Fifth Third Momentum(R) Savings: Fifth Third publishes no APY on the savings page and directs customers to a branch or banker for promotional rates. No APY is asserted. page checked
