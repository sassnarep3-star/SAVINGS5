# SAVINGS5 — Verified savings-account research

A fully sourced comparison of savings accounts at large national U.S. banks, published as a
GitHub Pages site. Rates, returns by deposit size, FDIC-insurance maximisation, opening
bonuses, account rules, and every irregularity found along the way.

**Site:** https://sassnarep3-star.github.io/SAVINGS5/

## The rule this repo is built on

> Every published figure was read from an official source and links to it on the row.
> Anything that could not be confirmed from an official source is **left blank**, marked
> `unverified`, and written up on the Flagged for Review page. Nothing is inferred,
> estimated, averaged or recalled.

Aggregator sites (Bankrate, NerdWallet, Forbes Advisor, Investopedia …) were never used as a
source of record. Web search was used only to locate official URLs.

## What is here

| Path | Contents |
|---|---|
| `docs/` | The generated site (GitHub Pages serves this folder from `main`). Do not edit by hand. |
| `data/accounts.json` | 18 institutions / 23 products. Per-field `value` + `status` + `source_url` + the bank's own "as of" date. |
| `data/fdic.json` | SMDIA, ownership categories and coverage limits, all sourced to `fdic.gov`. |
| `data/benchmarks.json` | FDIC National Rates and Rate Caps, as of 2026-10-19. |
| `data/bonuses.json` | Opening bonuses and promotional APYs, with the full qualifying rules. |
| `data/flags.json` | 20 irregularities and unverifiable fields. |
| `data/returns_model.json` | Machine-readable restatement of each captured balance→APY tier table. |
| `data/returns.json` | **Derived.** 756 projections, regenerated by the build. |
| `data/SCHEMA.md` | The field-level verification contract. |
| `scripts/build.py` | Generates `data/returns.json` and the whole of `docs/`. |
| `COORDINATION.md` | Shared task board, source log, irregularity log, activity log. |

## Build

```bash
python3 scripts/build.py      # no dependencies beyond the standard library
```

The build **fails** if any modelled APY is absent from the captured tier table, if any record
marked `unverified` still carries a value, if any published product lacks a source URL, or if
any internal link on the site does not resolve.

## Return model

```
ending balance = principal × (1 + APY) ^ (days / 365)
```

Account-opening date `2026-10-22`; deposit sizes $1k / $10k / $25k / $50k / $100k / $250k;
horizons 30 / 90 / 180 / 365 / 730 / 1095 / 1826 days. The APY used is the one applying to that
balance band, not the headline rate. Every savings APY here is variable — the projections hold
it constant, which will not happen in practice.

## Not financial advice

A research summary captured at one moment in time (2026-10-22 00:00 UTC). Re-check any rate on
the institution's own page before funding an account.
